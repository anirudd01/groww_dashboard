# INDmoney (INDstocks API) — as used by the sector heatmap

INDmoney's trading API is branded **INDstocks**. The full vendor docs are
mirrored in [`../indstocks-api-docs.md`](../indstocks-api-docs.md); this page
records what the heatmap actually uses, what was **verified against the live
API on 2026-09-25 during market hours**, and how it compares with Dhan.

Implementation: [`market/providers/indmoney.py`](../../market/providers/indmoney.py).
Instrument ids: the `indmoney_instruments` set in `data/market.db`,
generated by [`scripts/indmoney.py --master`](../../scripts/indmoney.py).

---

## Setup

```bash
# .env
IND_MONEY_CLIENT_ID=...     # shown at indstocks.com/app/api-trading/access-tokens after Setup TOTP
IND_MONEY_MPIN=...
IND_MONEY_TOTP_SECRET=...   # the base32 Setup Key
```

- No access token in `.env`: [`indmoney_session.py`](../../market/providers/indmoney_session.py)
  mints one with `POST /generate/token` and shares it through the `indmoney_session` row of `data/market.db` under a file lock. Every provider and script takes it
  from there (`IndMoneyProvider().connect()`); a stale `IND_MONEY_ACCESS_TOKEN`
  is ignored with a warning.
- Sent raw in `Authorization` — no `Bearer` prefix.
- A JWT valid until **07:00 IST the next day**; the provider logs the hours left.
- A new token revokes the old one, so it is minted only when none is usable, or
  when INDmoney rejects the saved one (a 401, or a 403 naming the token - never a
  `UserException`). Wrong codes are retried once at most: five lock generation
  out for 15 minutes.
- **Free.** No data plan needed (Dhan needs its paid Data API plan).
- Static-IP whitelisting applies to order placement only, so market data works
  from any machine.

Select it in the dashboard sidebar (**Data provider → INDmoney**), or:

```bash
PULSE_MARKET_PROVIDERS=indmoney                          # INDmoney only
python scripts/debug/check_heatmap_universe.py --provider indmoney
python scripts/debug/check_heatmap_universe.py --provider indmoney --board indices
```

## Endpoints used

| Purpose | Call | Notes |
|---|---|---|
| Auth check | `GET /user/profile` | Validates the token |
| Instrument ids | `GET /market/instruments?source=equity\|index` | **Script only**, never at runtime. Needs the token (Dhan's master is public) |
| Live price (REST fallback) | `GET /market/quotes/ltp?scrip-codes=NSE_2885,...` | Up to 1000 codes per call |
| Previous close, day bars | `GET /market/quotes/full?scrip-codes=...` | `prev_close`, `day_open/high/low`, `volume` |
| Previous close after hours | `GET /market/historical/1day?scrip-codes=...` | **5 codes per call** — 10 calls for the Nifty 50, ~5 s |
| Live feed | `wss://ws-prices.indstocks.com/api/v1/ws/prices` | `quote` mode, token in the handshake header |

Rate limits: 5 requests/second in each of the Quote and Data buckets. The
provider throttles to 4/s with process-wide gates, because the limit is per user
and the dashboard runs one provider per board. Up to 3 websocket connections per
user, 3000 instruments each.

## Behaviour verified live (where the vendor docs are silent or wrong)

| Finding | What the docs say | What actually happens | What the code does |
|---|---|---|---|
| **Index prefix** | Websocket example uses `NIDX:26000`; REST prefix for indices undocumented | REST needs `NIDX_40000001`, socket needs `NIDX:40000001`, using the ids from the index instrument file. `NIDX:26000` is **silently ignored** — no error, no ticks | `rest_code()` / `feed_code()` |
| **Frames are double-encoded** | Price-feed frames shown as plain JSON | Every frame is a JSON *string* whose contents are JSON (the docs mention this only for the order feed) | `decode_frame()` unwraps up to twice |
| **Quote-mode `close`** | Response shape for `quote` mode not documented | `{open, high, low, close, volume}`, and `close` is the **live price**. It matched LTP-mode `ltp` exactly, tick for tick, on every instrument tested. It is *not* the previous close | One `quote` subscription carries both price and day bar |
| **Instrument key in frames** | — | Bare id (`"2885"`), no segment | Each board is one segment with its own feed, so it is unambiguous |
| **One bad code poisons a batch** | — | Any unknown scrip code fails the **whole** request with `400 Invalid scrip codes or mode` | Only resolved ids are ever sent |
| **Partial first response** | — | The first batched `/quotes/full` call of the session returned 5 of 17 indices. Identical calls afterwards returned everything | Previous-close fetches ask again for anything missing |
| **Short candle batch** | — | Seen 2026-09-30 after the close: 6 of 17 indices had no previous close (one batch of five, plus Oil & Gas), a grey board with a "Data gaps" panel. Not reproduced in three later runs, which returned 16/17 | `get_prior_session_close` asks once more for whatever the first pass missed |
| **Index volume** | — | Always `0` | Kept as "unknown", not a zero |
| **Daily candle `ts`** | "Unix epoch seconds (IST)" | Midnight UTC of the trading day (05:30 IST). The date is correct in either zone | Parsed as an IST date |
| **Index file layout** | Documented correctly | 3 columns, and the one labelled `SEGMENT` holds the index **name** | The script reads it positionally |

### Nifty Oil & Gas is not served

`Nifty Oil & Gas` (`40000104`) is in INDmoney's index file, but on 2026-09-25 it
returned **nothing on every surface**: absent from quotes, `"candles": null`
from history, no ticks on the socket. On the INDmoney index board it shows as a
data gap (16/17 indices priced). The mapping is kept, so it starts working as
soon as INDmoney serves the index — rerun `scripts/debug/check_heatmap_universe.py --board
indices` to see.

### Index name mapping

Cash-equity ids are the NSE token, identical to Dhan's for all 50 stocks, ISINs
included. Index ids are INDmoney's own (`40000001` for Nifty 50; Dhan uses
`13`), and INDmoney names indices differently (`BANK NIFTY` where the dashboard
says `BANKNIFTY`). `INDEX_NAMES` in the generator script is the translation.
Each of the 16 served indices was checked against Dhan at the same moment: live
values within 0.01%, **previous closes identical**. `FINNIFTY` is `Nifty
Financial` (`40000100`), not `NiftyFinSrv25 50`, which is the capped 25/50
variant.

## Capability comparison with Dhan

For what the sector heatmap needs. "Same" means verified on the same instruments
at the same moment.

| Capability | Dhan | INDmoney |
|---|---|---|
| Cost of market data | Paid Data API plan | **Free** |
| Credentials | `DHAN_CLIENT_ID` + `DHAN_PIN` + `DHAN_TOTP_SECRET`; the 24 h token is minted from TOTP | `IND_MONEY_CLIENT_ID` + `IND_MONEY_MPIN` + `IND_MONEY_TOTP_SECRET`; the token (to 07:00 IST) is minted from TOTP |
| Nifty 50 equities | 50/50 | 50/50 |
| NSE sectoral indices on the index board | 17/17 | **16/17** — no Nifty Oil & Gas |
| Live websocket | Binary protocol | JSON (double-encoded) |
| Socket connect time | 0.17 s | 0.22 s |
| Price updates per stock, 30 s side by side | median 11 | median 11 |
| Price agreement with the other broker | — | median 0.000 %, max 0.035 % |
| Day open/high/low from the socket | Yes (quote packet) | Yes (quote mode) |
| Volume from the socket | Yes | Yes (0 for indices) |
| Previous close pushed by the socket | Documented (packet code 6) | No — comes from REST |
| Previous close in session (REST) | `/marketfeed/ohlc` | `/quotes/full` → `prev_close` |
| Previous close after hours (candles) | 1 symbol per call, ~13 s for 50 | 5 symbols per call, **~5 s** for 50 |
| REST quote rate limit | 1/s | 5/s |
| Websocket connections allowed | 5 | 3 |
| Instrument master | Public, 35 MB CSV | Needs token, 3 MB CSV + a small index file |

**Bottom line for this dashboard:** INDmoney covers everything the heatmap uses
from Dhan, except one index (Nifty Oil & Gas). Its live data matched Dhan's
tick rate and prices over the test window, it costs nothing, and its REST limits
are looser. The one thing to watch is the 3-connection cap: both boards plus a
`scripts/debug/check_heatmap_universe.py` run already use all three.

Not compared, because the heatmap does not use them: market depth, option
chains, historical intraday candles, and anything order-related.
